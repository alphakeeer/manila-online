# T13：随时贷款与赎回的联机入口

Phase 3 · 推荐 agent：Terra。财务操作不遵循普通行动回合门禁，需验证并发与竞拍交互。

执行前阅读 [架构约定](../ARCHITECTURE.md) 和 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

玩家可在游戏中查看自己的抵押状态并合法贷款/赎回，不影响其他玩家决策的正确性。

## Scope

- 加入独立 mortgageShare/redeemShare 协议、服务端适配与 self 视图财务面板。
- 非当前行动玩家可操作自己的股份；命令仍遵守房间 revision、事务和幂等规则。
- 竞拍承诺与实际抵押状态变化后刷新相关 self/decision，UI 使用中文货物和贷款说明。

## Non-goals

- 不将“任何时候”扩展为已结束房间可改分，不新增转账/交易。
- 不重复修改 T03 已修复规则，不公开其他玩家的现金和抵押明细。

## Dependencies

- [T12 联机三轮移动、领航与海盗](T12-voyage.md)

## Acceptance Criteria

- 当前玩家和非当前玩家均可合法贷款/赎回；伪造他人 shareId 或重复抵押被拒。
- 贷款 12、赎回 15、终局抵押扣款遵从引擎；余额不足拒绝不改变状态。
- T03 复现通过实际 API 后现金为 11；他人财务动作造成 revision 改变时当前玩家能安全刷新并重试。

## Validation

- 三浏览器测试等待时财务操作、余额展示、竞拍中抵押、重复提交及过时 revision。
- 集成测试验证自己/他人 shareId、已抵押/已赎回/游戏结束，并检查所有接收者 payload。
