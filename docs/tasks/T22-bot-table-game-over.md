# T22：本地机器人对局与终局结算画面

Phase 4 补充 · 推荐 agent：Luna。前端与开发工具任务，不修改规则引擎、协议或服务端。

执行前阅读 [T21](T21-play-experience.md) 与 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

让开发者在本机一键开出多个真实浏览器窗口、由随机机器人打完整局以观察实际表现；终局时提供好看的结算与统计画面。

## Scope

- 开发服务器专用 `?bot=1` 随机托管：只从当前 decision 提供的选项中选择，被拒后改用最稳妥选项，限流时退避；可在页面暂停/接手。
- `npm run bots` 脚本：Playwright 有头浏览器、每座位独立上下文、窗口平铺（可含手机视口），自动建房/加入/准备/开局并输出终局排名。
- 终局画面：冠军标题与收市原因、2-1-3 领奖台、名次/财富/最佳航程/舢板去向统计、每航程收益柱图、收入来源堆叠条、货物行情折线（悬停提示与数据表），可收起查看棋盘。

## Non-goals

- 不提供生产环境托管/AI；不新增服务端统计投影；不支持终局后离房再开（服务端只允许大厅阶段离房）。

## Dependencies

- [T21 游玩体验与动效重构](T21-play-experience.md)

## Acceptance Criteria

- 机器人只产出协议合法、且属于当前 decision 选项的动作（单元测试覆盖全部决策类型）。
- 四窗口（含一个手机视口）机器人对局无卡死地打到终局；生产构建不含机器人开关。
- 终局画面在桌面与手机视口可读，三条既有 Chromium E2E 继续通过。

## Validation

- `npm test`、`npm run build`、`E2E_FULL_GAME=1 npm run test:e2e`（放宽限流）。
- `npm run bots -- --players 4 --phones 1` 实跑一局，并截图复核终局画面。
