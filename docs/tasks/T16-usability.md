# T16：移动端、键盘与错误反馈收尾

Phase 4 · 推荐 agent：Luna。在既定视图和命令接口内调整交互，边界清楚、可独立回归。

执行前阅读 [架构约定](../ARCHITECTURE.md) 和 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

桌面和手机玩家都能看清状态并完成全部已实现操作。

## Scope

- 完善小屏布局、表单中文标签、等待/pending/冲突/断线/关闭状态；不新增协议。
- Dialog 补齐焦点圈定及焦点恢复，按钮可用键盘操作；行情计时器卸载清理。
- 保留非动画结果呈现，支持 reduced motion；为常见错误提供明确下一步。

## Non-goals

- 不更换视觉风格、不重构所有组件、不增加拖拽专属交互。
- 不改变鉴权、回合规则或通过 UI 猜测裁决结果。

## Dependencies

- [T14 结算记录与完整对局结果](T14-settlement.md)

## Acceptance Criteria

- 至少 390px 手机和 1280px 桌面宽度可完成登录、房间、所有决策和财务操作，无不可达按钮。
- 键盘可打开/操作/关闭对话框，Tab 不穿透模态，Escape 和焦点恢复正常。
- 断线只读和 revision 冲突反馈可区分；卸载组件后无未清理计时器，动画关闭不影响理解。

## Validation

- 组件测试焦点、计时器清理、错误和 pending；真实浏览器两种尺寸保存验证截图。
- 键盘走完登录/房间/竞拍/财务，检查可访问名称、文字对比和触控目标；运行已有 UI 测试及 build。
