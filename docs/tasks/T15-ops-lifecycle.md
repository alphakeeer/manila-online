# T15：Token 撤销与异常房间管理

Phase 4 · 推荐 agent：Terra。撤销与在途命令、持久会话和在线连接存在一致性要求。

执行前阅读 [架构约定](../ARCHITECTURE.md) 和 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

管理员能撤销门禁和关闭无法继续的房间，避免失效身份仍操作游戏。

## Scope

- 扩展主机 CLI：按安全标识列出/撤销 Token、列出/关闭房间；不展示原始凭证或玩家私人状态。
- 实现撤销提交与后续命令授权的顺序保障，关闭关联连接；到期检查复用服务端时钟。
- 实现架构规定的 lobby 空置关闭、关闭房间只读、对应客户端提示和脱敏日志。

## Non-goals

- 不做 Web 管理后台、自动代打、强制夺位或对局中换人。
- 不自动删除历史、不通过人工修改数据库改变比赛结果。

## Dependencies

- [T14 结算记录与完整对局结果](T14-settlement.md)

## Acceptance Criteria

- 撤销完成后关联会话不能提交新命令或订阅，在线连接被关闭；命令与撤销竞态有确定顺序并可验证。
- 过期连接最多 30 秒内关闭，入站请求即时校验；被撤销/过期客户端清理私人界面。
- 24 小时无业务活动的 lobby 关闭，playing 不自动关闭；关闭动作持久且可重复执行，保留游戏快照。

## Validation

- 真实数据库并发撤销/提交测试，明确撤销先成功则后续命令绝不成功；检查 CLI 输出和日志无秘密。
- 三浏览器共享 Token 撤销后全退出；另一个 Token 的房间不受影响。
- 可控时钟测试有效期/大厅超时，管理员关闭后重启确认仍关闭且不再次推进引擎。
