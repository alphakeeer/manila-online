# T18：发布前多端故障与完整对局验收

Phase 4 · 推荐 agent：Terra。跨层回归与故障注入决定是否真正具备公网多人能力。

执行前阅读 [架构约定](../ARCHITECTURE.md) 和 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

用自动化证据确认完整多人对局、隔离、恢复与持久化满足 MVP。

## Scope

- 整合各切片已有测试，不把基础验证推迟到本任务；新增遗漏的 3/4/5 人、两种海盗规则矩阵。
- 至少三独立浏览器完整玩到终局；用测试专用种子/fixture 加速，不给生产暴露任意设 seed 或改状态接口。
- 覆盖并发/重试/断网/重启/撤销/数据库故障/未知版本；加入 CI 干净安装、build、单元、集成及关键 E2E。

## Non-goals

- 不以随机模拟代替真实网络链路，不建设压力测试平台。
- 不顺带大改功能；发现缺陷先登记可复现证据和所属任务，再小范围修复。

## Dependencies

- [T15 Token 撤销与异常房间管理](T15-ops-lifecycle.md)
- [T16 移动端、键盘与错误反馈收尾](T16-usability.md)
- [T17 按需加载与图片体积预算](T17-assets.md)

## Acceptance Criteria

- 规则矩阵均能结束；三浏览器完整对局后共享结果一致，各私有视图不同且符合白名单。
- 已提交未 ACK 的操作重试不重复入账，进程重启不重掷骰或重复结算，数据库故障无伪成功。
- 未登录/非成员/失效 Token/伪造动作/恶意多余字段被拒；REST/WS/历史/日志均无禁发字段。
- CI 可从新检出执行，随机种子和失败诊断可重现，无依赖开发者个人数据库的假通过。

## Validation

- 运行 npm ci、npm test、npm run build、npm run test:integration、npm run test:e2e，记录环境和测试数量。
- 执行固定 seed 的 3/4/5 人规则模拟与真实浏览器全局测试；保留失败 trace，报告覆盖和仍未覆盖项。
- 检查生产依赖图仍无前端 game 裁决入口；对测试专用端点验证生产不可达。
