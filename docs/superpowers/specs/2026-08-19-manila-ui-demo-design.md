# 马尼拉最小 UI 视觉演示设计

## 目标

在现有 Vite + React 项目中实现一个纯前端、响应式的视觉演示页，用真实《马尼拉》素材展示桌面和手机网页的最终界面方向。演示使用固定三人局数据，不连接后端，也不调用规则引擎推进游戏。

## 范围

演示只包含一个“进行中的航程”页面，并提供四个可切换视觉场景：

1. 主桌面：版图、玩家状态和放置同伙决策。
2. hot-seat 交接遮罩：隐藏私人信息并提示把设备交给指定玩家。
3. 私人股份抽屉：展示当前玩家股份及抵押状态。
4. 航程结算弹层：展示货物抵港、比索变化和黑市行情上涨。

不实现游戏准备、真实规则计算、完整航程推进、存档、联网、后端、音效或复杂动画。

## 视觉方向

采用“南洋商行”风格：

- 深绿作为页面和版图容器背景。
- 旧纸色作为决策面板、抽屉和弹层底色。
- 朱砂红作为主按钮和当前行动强调色。
- 黄铜色用于航程、港务长、费用和边框强调。
- 标题使用系统衬线字体栈，正文使用清晰的系统无衬线字体栈，不加载外部字体。
- 保留素材原本的年代感，不给版图添加现代高饱和滤镜。

## 响应式布局

### 桌面（宽度不小于 900px）

- 顶部依次显示品牌/航程栏和横向玩家状态条。
- 主区域约三分之二宽度用于纵向版图，约三分之一用于固定决策栏。
- 版图居中完整显示，示例舢板和热点使用百分比坐标覆盖。
- 决策栏始终可见，展示当前阶段、规则提示、两个合法位置和确认/放弃按钮。

### 手机（宽度小于 900px）

- 顶部仅保留航程、当前玩家和比索摘要。
- 版图占首屏约一半高度，可在容器中完整缩放查看。
- 决策内容改为底部抽屉，带拖拽把手的视觉提示，但演示版不实现真实拖拽。
- 底部导航提供版图、玩家、我的股份和规则入口；“我的股份”可以打开私人抽屉。
- 所有主要点击区域至少 44px，高度适配安全区。

## 页面组成

- `DemoToolbar`：演示场景切换，只用于查看主桌面、交接、股份和结算状态。
- `VoyageHeader`：品牌、航程和简化规则入口。
- `PlayerStrip`：三名玩家的比索和股份摘要，突出当前玩家及港务长。
- `BoardStage`：真实版图底图、三艘示例舢板、行情标记和合法位置热点。
- `DecisionPanel`：统一内容，在桌面作为侧栏、手机作为底部抽屉。
- `SharesDrawer`：当前玩家的私人股份，使用已有股份图片并标识一张抵押示例。
- `HandoffOverlay`：全屏隐私遮罩和“确认接手”按钮。
- `SettlementModal`：航程结果、比索变化、抵港货物及行情变化。

组件只消费同一个固定 `demoState` 展示模型。场景切换和选项高亮使用 React 本地状态；不复制或修改规则引擎状态。

## 素材策略

- `game_board.jpg` 作为版图底图。
- 四张股份图片用于私人股份抽屉和结算摘要。
- 比索图片用于资金变化和玩家摘要的装饰性图标。
- `ware_cards.jpg` 用于货物说明缩略图。
- 缺少独立舢板、骰子和同伙素材时，使用与货物对应的 CSS 图形和文字缩写，不生成新图片。
- 素材通过 Vite 静态导入或 `new URL(..., import.meta.url)` 打包，生产构建不得依赖仅开发服务器可访问的绝对磁盘路径。

## 交互行为

- 点击两个放置选项会切换选中状态；确认按钮只显示短暂的视觉反馈，不调用 `transition`。
- 点击玩家私人区域或底部“我的股份”打开股份抽屉，关闭后回到主桌面。
- 交接场景默认隐藏桌面，点击“确认接手”后回到主桌面。
- 结算场景使用模态层展示固定结果，关闭后回到主桌面。
- 场景切换工具在桌面右上角、手机折叠菜单中出现，并明确标注“演示”。
- 所有交互可用鼠标和键盘完成；弹层打开时提供可见关闭按钮并使用合理的 ARIA 标签。

## 错误与降级

- 素材保留有意义的替代文本；若图片加载失败，容器仍显示货物名称或版图区背景色。
- 视口低于 320px 时保持单列并允许页面纵向滚动，不出现水平页面滚动。
- 演示数据为本地常量，不存在网络加载态或后端错误态。

## 验收与测试

- 桌面 1440×900 下可同时看到完整玩家条、版图和决策栏。
- 手机 390×844 下版图位于上半屏，决策抽屉不遮挡顶部玩家摘要，页面无水平滚动。
- 四个演示场景均可从界面切换并返回主桌面。
- 放置选项、股份抽屉、交接确认和结算关闭均有可见反馈。
- 使用统一术语：舢板、比索、港务长、同伙、股份、黑市行情表、航程。
- 现有规则引擎测试继续通过，新增 UI 行为测试覆盖场景切换和选项选择。
- `npm test` 与 `npm run build` 均以退出码 0 完成。
