# T11：统一联机放置、抵押和偷渡交互

Phase 3 · 推荐 agent：Terra。两个 UI 入口和财务选择必须生成同一安全命令。

执行前阅读 [架构约定](../ARCHITECTURE.md) 和 [实际状态](../STATUS.md)；任务完成状态只在 STATUS 维护。

## Goal

轮到的玩家可从版图或面板完成一致的放置操作，直到首轮移动。

## Scope

- 增加放置/放弃 wire schema、服务端适配和视图；复用权威财务处理。
- 版图点击只选位置，共用确认区处理 collateral/stowaway/费用；保留面板可访问操作。
- 分离决策身份与 revision：新决策清空临时表单，同阶段更新也剔除失效抵押/位置。

## Non-goals

- 不改放置费、偷渡资格、三人额外放置轮。
- 不在浏览器自行判断某动作可改变规则状态。

## Dependencies

- [T10 联机购股、选货与下水](T10-launch.md)

## Acceptance Criteria

- 普通、抵押、偷渡、保险和放弃均按引擎处理；相同位置通过任一入口提交的命令一致。
- 其他人的交互不可提交，重复点击/断网重试无双扣款或双占位。
- 三人两轮放置后、四/五人一轮后进入首轮移动，所有接收者状态一致。

## Validation

- 三种人数 integration 测试轮转；浏览器覆盖热点/面板及资金不足、偷渡、已占用位。
- 覆盖 U01/U02 回归、finance 修改导致选中 collateral 失效、拒绝后 UI 可恢复操作。
